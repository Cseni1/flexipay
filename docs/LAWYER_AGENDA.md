# Questions for the UK lawyer (FLEXIWORK LTD / FlexiPay)

Prepared for the legal consultation. Answers to be filled in by the lawyer.

| # | Topic | Question | Answer |
| --- | --- | --- | --- |
| 1 | FCA promotions | We want UK users to be able to buy USDC with a card through a provider's widget embedded in our app. Does this make FlexiPay a financial promotion of cryptoassets, and what do we need before enabling it for UK users? | |
| 2 | Licensing with a wallet provider | If a licensed wallet and ramp provider (for example Crossmint) holds the wallets and processes the fiat, does FlexiWork still need any registration or authorisation for offering FlexiPay in the UK? | |
| 3 | API model | FlexiPay is an API and dashboard. Other software companies use it to take payments from their customers. Which regulated activities, if any, are we carrying out, and which are carried out by our providers? | |
| 4 | Stablecoin payments at a till | A UK business wants to accept GBP-denominated stablecoin payments from customers who scan a QR code with their own wallet. What are the rules for the business, and for us as the software provider? | |
| 5 | Tips and service charge | If our customers' software splits tips and service charge between staff using on-chain transfers, which UK rules apply (tronc and employment tips rules), and what must we avoid doing? | |
| 6 | Travel Rule | Do we have any Travel Rule obligations if users send stablecoins between their own wallets through our product? | |
| 7 | Customer funds | If funds only ever move wallet to wallet and we never hold them, is that sufficient for us to say we do not take custody, and how should we word that to providers? | |
| 8 | Company details | Our registered business activities are software development and employment agency activities. Do we need to add or change a business activity code before applying to payment or crypto providers? | |
| 9 | Terms and disclosures | What terms of use, risk warnings and disclosures should the app show before launching to real UK users? | |
| 10 | Next steps and cost | What do you recommend we do first, and what would it cost? | |
